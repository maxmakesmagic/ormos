It's time for the finale of Core Set Survivor! But first, let's recap how we got here and explain the concept for people who just got here.

The original **Magic** core set was *Limited Edition Alpha*, which contained [285 cards](https://web.archive.org/web/20110525000000/http://gatherer.wizards.com/Pages/Search/Default.aspx?output=spoiler&method=visual&action=advanced&set=%5B%22Limited+Edition+Alpha%22%5D&type=+!%5B%22Basic%22%5D), not counting basic lands. Then all of those cards were reprinted in *Limited Edition Beta*, which also added [Circle of Protection: Black](https://web.archive.org/web/20110525000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Circle+of+Protection%3A+Black) and [Volcanic Island](https://web.archive.org/web/20110525000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Volcanic+Island), which had been mysteriously left out of Alpha.

Then *Revised* had a slightly different set of cards, and only 250 of the cards from Alpha were still in the core set. *Fourth Edition* changed the core set again, and only 211 cards had been in every core set.

You get the idea. Here's the complete breakdown:

> ***Alpha*** : [285](https://web.archive.org/web/20110525000000/http://gatherer.wizards.com/Pages/Search/Default.aspx?output=spoiler&method=visual&action=advanced&set=%5B%22Limited+Edition+Alpha%22%5D&type=+!%5B%22Basic%22%5D)  
> ***Revised***: [250](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-32)  
> ***Fourth Edition***: [211](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast)  
> ***Fifth Edition***: [151](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-29)  
> ***Sixth Edition***: [79](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-28)  
> ***Seventh Edition***: [60](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-20)  
> ***Eighth Edition***: [40](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-25)  
> ***Ninth Edition***: [24](/en/articles/makingmagic/2005/07-25-outwit-outplay-outlast-7)  
> ***Tenth Edition***: [16](https://web.archive.org/web/20110525000000/http://archive.wizards.com/Magic/Magazine/Article.aspx?x=mtg/daily/askwizards/0908#survivor)  
> ***Magic 2010***: [8](https://web.archive.org/web/20110525000000/https://magic.wizards.com/en/articles/archive/core-set-survivor-magic-2011-edition-2010-06-09)  
> ***Magic 2011***: 2

That's right. In ***Magic** 2011* there were only two cards that had appeared in every core set since *Alpha*. They're [Giant Growth](https://web.archive.org/web/20110525000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Giant+Growth) and [Giant Spider](https://web.archive.org/web/20110525000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Giant+Spider).
