* * *

Since early this week, we've been having stability issues with ***Magic** Online.* As we've stated before, the stability of the game is our top priority. Crashing once every twenty minutes is far from acceptable, so we're going to take some drastic measures. 

In my column on **magicthegathering.com**, I've hinted at the code that was going to be tested on the beta server after the *Darksteel* set went live. And, as many of you have guessed, that is the code for the **Premier Events** room. We were hoping to get through the release events and then, sometime in the next few weeks, we were going to have an open beta of this code. That code is, right now, sitting on the beta server ready for load testing.

What does that have to do with today's problems? The **Premier Events** code is intertwined with the master server stability issue. The new beta server code has been cleaned up enough to make the **Premier Events** room viable for testing. 

Since we can't get the live server stable, we're going to take it down temporarily. That doesn't mean you'll be unable to play the game, however. Here's what's going to happen:

*   Sometime in the next hour, the live server is going offline. (Yes, we're predicting this one.) The store will also be taken down.  
  

*   The next time you log on, your account will be redirected to the ***Magic** Online* beta server. This will last for the following 24 hours or so.  
  

*   On the beta server, your account won't have your normal cards in it. **Edit:** Okay, looks like we won't be able to grant everyone four of every card. We will give you cards to play with, however, and you won't have to provide product for Limited events, anyway.[**\***](#anchor)  
  

*   Also during that time, **Premier Events** will be available for you to participate in.  
  

*   **Update:** We won't be granting cards directly to accounts until sometime tomorrow. However, since you don't have to provide product for Limited events, you can play in those for free in the meantime.  
  

*   **Update:** Current plan for *Darksteel* leagues is to resume where they left off.  
  

*   **Make sure you close and restart *Magic Online* to update your client.** Otherwise, you won't connect to any server.

*This is the beta server, so you can expect some instability on it, as well.* However, the code on the beta server is a cleaned-up version of what's on the live server. We're hoping that this means more stability than we currently have on the live server. At the very least, our programmers have been working with the beta master server code enough that they have a better chance of finding crash bugs on it than the current live code. 

Over the next 24 hours, we'll be able to gather some information on the load capabilities of the new code. Also during that time, we'll be preparing a version of the beta code that includes *Darksteel* cards and additional reporting functionality for the programmers. Then, at the end of that time, we'll meet and decide what the next step is. 

Yes, things are pretty dark right now. But the beta code has fixes in it that we've never propped to the live server. What we're hoping is that, in the end, pushing forward on the beta code right now will bring us a more stable server along with the **Premier Events** room much sooner than expected. 

**\***The cards in your account will remain in our live databases. Once we point accounts back at the live server, your collection will be exactly the same as before. This should be within the next two days. This is both due to how long it will take us to port over all the account information, and because we can't allow trading of real cards while on the beta server.

We apologize for the interruption of the *Darksteel* release events. We hope that the ability to play for free for the next day or so will help make up for the frustration and inconvenience.
