### List of Changes

* * *

*   Added tournament modifications and new prize tables.
*   Fixed Catalyst Stone so it correctly affects paying X in the cost.
*   Modified Recoup to match current errata for targeting cards that have flashback already.
*   Changed menu text for Recoup targeting cards with multiple ways to play (modal, kicker, etc.).
*   Fixed bug that crashed game if a creature that can block multiple creatures (i.e., Luminous Guardian) is blocked by multiple creatures and has its power reduced to 0 or less.
*   Fixed range enforcement bug for multiplayer games.
*   Added Avatar digital object functionality to Collection screen.
*   Fixed bug that caused Nameless One to go to the graveyard while face down.
*   Modified name display for tokens affected by Artificial Evolution.
*   Reordered format list on menus.
*   Fixed naming when Clone targets Goblin Soldiers.
*   Fixed interaction between Canopy Claws and Serra's Embrace. (Canopy Claws targeting a creature enchanted by Serra's Embrace removes flying.)
*   Fixed Root Greevil/Shifting Skies interaction.
*   Fixed Confessor/Zombie Infestation/Nefarious Lich combination crashing games.
*   Fixed Menacing Ogre to allow choosing 0.
*   Modified Lobotomy to reveal players' hands (Oracle ruling).
*   Fixed Cephalid Shrine prompting for "garbage" mana to pay X.
*   Added display of players' hands for players replaying or watching games where cards are used that reveal players' hands.
