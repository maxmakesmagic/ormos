Hello, everyone!

The *[Phyrexia: All Will Be One](https://web.archive.org/web/20230208000000/https://magic.wizards.com/en/products/phyrexia-all-will-be-one)* Update Bulletin is the place to find information about changes to the *Magic* Comprehensive Rules that are coming with the set's release, as well as updates to the official text of some cards. This document is written while the rules and card text changes are still going through editing, so it's possible they'll be a little different from the final changes. When the rules are finalized, you'll be able to see them on the [rules page](https://web.archive.org/web/20230208000000/https://magic.wizards.com/en/game-info/gameplay/rules-and-formats/rules). Once the set is live, official Oracle card text for each card can be found at [Gatherer](https://web.archive.org/web/20230208000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?multiverseid=508148).

Alright. Let's dive in!
