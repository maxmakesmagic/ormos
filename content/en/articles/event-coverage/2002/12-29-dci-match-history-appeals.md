### Match History Appeals

A Match History Appeal is a formal request to correct a possible error in a player's match history. If you participate in DCI sanctioned tournament, and believe the match results of an event were erroneously reported to the DCI, you may file an appeal to have the error corrected. Before filing an appeal,

*   Read the DCI Match History Appeals Policy. This document is available in [HTML](/en/articles/event-coverage/undated/dci-match-history-appeals-policy).

*   Review the DCI Match History Appeals Form. This document is available in [PDF](http://www.wizards.com/dci/downloads/DCI_MHA_Form_2001.pdf).

### Missing Tournament Inquiry

If you have participated in a DCI sanctioned event, and it is listed as Delinquent six weeks after the event, you may file a Missing Tournament Inquiry. Once we verify that the event results have not been submitted, we will contact the tournament organizer to attempt to locate the event results. To see if the results of an event have been submitted, check the Tournament Locator page, located [here](https://web.archive.org/web/20021229000000/http://ww2.wizards.com/Site/LeavingWizards.aspx?url=http://webapp.wizards.com/dcitournament&origin=). Missing Tournament Inquiries can only be filed for events that are listed as Delinquent on the event page, or if the event has been listed as Received for more than two weeks.

*   First, check on the [Tournament Locator Page](https://web.archive.org/web/20021229000000/http://ww2.wizards.com/Site/LeavingWizards.aspx?url=http://webapp.wizards.com/dcitournament&origin=) for the event in question.

*   Once you find the event in question, click on the name of the event to check the status of the event. If the event is more than six weeks old and is listed as Delinquent, you can file a Missing Tournament Inquiry.

Send an email with the following information to DCI@wizards.com with "Missing Tournament Inquiry" in the subject line of the email:

*   Player's complete name, address, and DCI number,
*   The date of the event,
*   The format of the event,
*   The event Status,
*   Complete event location information (address),
*   The event coordinator’s name

As it often takes two to four weeks event results to be submitted and processed, please do not file a Missing Tournament Inquiry sooner than six weeks after an event has occurred. Missing Tournament Inquiries that are not submitted according to these instructions may not receive a timely response.

If the results of an event as listed as Processed, and you are not listed as a participant, you will need to file a Match History Appeal.

### Invitation and Bye-related Appeals

Players that want to file an appeal for an invitation to a higher-level event, or byes to a Grand Prix, should review the Appeals section of the Tournament Policy, located [here](/en/articles/event-coverage/undated/welcome-to-the-dci-document-center). It is strongly recommended that players use the Match History Appeals web form for invitation and bye-related appeals if it involves a correction to a player's match history.
