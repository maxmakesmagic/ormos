## PRODUCT INFORMATION

![](https://i.ormos.uk/85/bb/85bbe208a57ffc4e5e830fb1d3d55fd783581cc04d4bf57557ce4d864d1780c7.png)*Urza’s Legacy* features 143 cards, including randomly inserted foil premium cards. It’s the second set in Urza block, which features new mechanics like Cycling, Echo, Sleeping Enchantments, and Growing Enchantments.

**Set Name:** *Urza’s Legacy*  
**Block:** Set 2 of 3 of the *Urza* Block  
**Number of Cards:** 143

**Languages:** English, French, German, Italian, Japanese, Portuguese (Brazil), Spanish, Chinese Traditional

**Design Team:** Mike Elliott (lead), Bill Rose, Mark Rosewater

**Development Team:** Henry Stern (lead), Mike Elliott, William Jockusch, Bill Rose, Mark Rosewater
