![](https://media.magic.wizards.com/image_legacy_migration/sideboard/images/PTBAR01/548.jpg)*Brad Swan vs. Justin Gary*

　勝てばベスト８。余りに重要な一戦である。

**Game 1**

　Swan の Shivan Zombie が先陣。Justin の初手は除去に恵まれるものの、クリーチャーが無い。Opt を通してようやく発見した Phyrexian Battleflies を場に。Swanは Sparring Golem と続ける。

　何もアクションを起こさず、フルマナアンタップ状態の Justin に対し、Swan はまず Volcano Imp を召還し、相手がマナを使うかどうかを見定めたる。レスポンスが無い事を確認し Golem でアタック。

　Justin は Battleflies に Sisay's Ingenuity を張る。環境構築用というよりは更なるカードを求めて。そして、Imp に Mourning 。

　クリーチャーの出せない Justin を尻目に Swan は Nightscape Familiar と Thunderscape Apprentice とたたみかける。

　未だ Battleflies 一体である相手に対し、勿論 Swan はフルアタック。ここで Shivan Zomibe と Battleflies が相打ち。この Zombie は Recover により回収される。

　両者共、Bog Down と Hypnotic Cloud というディスカードスペルを抱えている。共に使用する絶好のタイミングを求めて。

　ドローに恵まれない Justin はまたもやそのままターンを返す。逆に Swan は Shivan Zomibe と Urborg Emissary　の二体を更に追加。

　既に推し量る状況では無くなってしまった。最早これまで、Justin は次のゲームに向けせめて情報収集をと Kicker で Cloud を放ち、Swan の手札にいた Dragon を確認した後に投了する。

　Justin 0 - Swan 1

**Game 2**

　今回のオープニングは Swan の Rogue Kavu 。Justin は Sky Weaver を出し、ライフとカードを天秤にかけた後、ライフを選択した。

　続いての Bog Down が Urborg Phantom と Hunting Drake ！ を Justin から奪い取る。それほどまでして残したカードは何か。Justin はそのうちの一枚である Obsidian Acolyte を召還する。

　Volcano Imp 、Power Armor と出し合い、更に Swan が Dromar's Attendant を。再び Imp に Mourning が張り付く。

![](https://media.magic.wizards.com/image_legacy_migration/sideboard/images/PTBAR01/550.jpg)*Brad Swan*

　ここで、なんと。従者が首を垂れて出てきたものとは。 Darigaaz's the Igniter そのものであった。

　早くもゲームがそしてマッチが決まってしまうのかに思えたが、Justin は Acolyte のバックアップ付きで Imp を召還。防衛ラインを構築する事に成功する。

　Vodalian Zombie を呼出したJustin の場にアンタップ状態の沼は無い。この状況で Swan は Shivan Zombie をキャストする。Ancient Spring をサクリファイスし Mourning を回収するか、はたまた破棄するかの二択をせまる。Justin は土地をさくり、回収することを選んだ。だが、これは今後の Power Armor と Acolyte の運用を難しくする。

　Merfolk に張られた　Sisay's Ingenuity。前回とは違い今回は、Merfolk と共にその能力を十分発揮する環境だ。

　Swan は二体目の Imp を場に出し、相手の隙を待つ。

　その時が来たと感じたのか、はたまたとりあえず殴らぬ事には未来が無いと思ったか。Imp と Darigaaz による二体アタックを行う。Justin の Imp がブロックしたのは…Impであった。以後の事を考えれば、毎回殴られるよりも、一度で今後の憂いを無くす方がよほど健全だ。

　実はこの間も Armor 装着型 Merfolk の攻撃が Swan をごりごりと削っている。一回のダメージが５点。さすがに、このままでは体がもたない。

　願いを込め Library を叩く Swan 。 　解答は無かった。その答えは両者が最後のゲームで探すことになる。

　Justin 1 - Swan 1

**Game 3**

　今回も Swan は Rogue Kavu によるスタート。Justin は Merfolk 。今回はライフよりカードを優先する。

　Nightscape Familiar に対し、Rogue Kavu に Mourningを。

　Volcano Imp に対してでてきたものは、 Darigaaz … 。はたしてこれに対抗する手段があるのか。

![](https://i.ormos.uk/9b/67/9b674acf8396faa00c2b53a520364f144b24a2d7ec5807bee464bb19021a9d33.jpg)*Justin Gary*

　Sky Weaver。飛べ Merfolk よ。願いはかなった。

　だが、Merfolk を飛ばし、マナを失った Weaver は Swan の Agonizing Demise によりそのあまりに短い生涯を終える。次なる手段は存在するのか。 Opt は　Justin に答えたのか。

　応急策として Mourning を移し変える。だが、その威力をそぐには足りない。

　それどころか、Dragon の元に新たな軍勢、Lava Zombie 、Imp が加わる。この難解なパズルに解答はあるのか。再度 Darigaaz はその気高き咆哮を上げる。 Justin のライフは６まで減少する。

　そして、次のカードを見た Justin は一瞬の輝きを目に浮かべる｡

　Hunting Drake 。決して恒久的では無いが、確実に次の解答へと繋がる可能性を秘めた解法である。

　Darigaaz の再訪。次なる解答は。

　再び Hunting Drake が彼のライフを救った。一時的なチャンプブロックではあるが。続いて Imp がその贄となり主の身代わりとなる。

　長き勝負にも終焉は必ず訪れる。 　延長タイムに入ってからの Swan の総攻撃、ついに Justin は力つきた。

　Justin 1 - Swan 2
