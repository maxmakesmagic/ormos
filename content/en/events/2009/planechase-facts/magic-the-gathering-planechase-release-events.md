*Planechase* Release Events are a great way to experience and celebrate the release of the newest way to play multiplayer **Magic** – *Planechase*! All participants receive a Tazeem promo plane card (while supplies last).

### Release Event Format

*   Each player will receive one of the four *Planechase* Game Packs. The game pack contains a 60-card **Magic** deck and a 10-card planar deck.
*   *Planechase* Release events will use an open play format. Players will be placed into game groups of 3-5 players. When a game finishes, players can play again or be regrouped into another game with new players.
*   Each player will receive a Tazeem promo plane card (while supplies last)
*   Contact your local Release Event Organizer for specific entry fee and event information.
