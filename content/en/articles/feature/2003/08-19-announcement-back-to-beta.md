### Free Beta Server Opens Tomorrow

* * *

I'm sorry you haven't heard much from me lately, but there hasn't been much to say. We're well aware of all the problems that you've been discussing on the boards and we're doing everything we can to solve them. Because of the degradation of stability over the past 48 hours, we're changing our tactics.

The current problems with ***Magic** Online* have made it unacceptable to continue any form of sanctioned play. All queues and tournaments will be taken down until further notice and will only be brought up again once we achieve a much more stable server.

Tomorrow morning, we'll be bringing up a free beta server. The beta server will run for a certain number of hours each day and allow the team to test radical code changes. I'll have more details on this tomorrow, and we'd appreciate everyone's help testing ***Magic** Online* out on those servers.

The live server will continue to run in the best state we can achieve and you're welcome to continue playing casual games on it. If it begins running with the type of stability we had at some points over the past weeks, we'll bring sanctioned play back online.

Please check back here tomorrow for information about the free beta servers.

-Dan
