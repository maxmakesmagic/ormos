Defending GP Singapore Champion たる Sam Lau と日本の若き小野田倫久による全勝対決が堂々の Feature Match に選ばれた。 小野田は典型的な R-B-G Void デッキ、Lau は典型的"B.B.B."である。

### Game 1

![](https://media.magic.wizards.com/image_legacy_migration/sideboard/images/GPSING01/972.jpg)

先攻の小野田が [Nightscape Familiar](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Nightscape+Familiar) を、Lau が [Gaea's Skyfolk](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Gaea%27s+Skyfolk) を召喚するという立ち上がり。小野田は 2 体目の Familiar を [Exclude](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Exclude) されてしまうも、 Skyfolk を即座に [Terminate](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Terminate) で葬りさってみせたのだった。小野田は [Crypt Angel](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Crypt+Angel) を召喚して見せたのだが、Lau はこれを [Mystic Snake](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Mystic+Snake) でカウンターし、タップアウトした瞬間に Familiar を Fire で除去したのだった。小野田もこの Snake は即座に [Terminate](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Terminate)。

Lau は中盤にさしかかると [Fact or Fiction](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Fact+or+Fiction) を経由して [Kavu Titan](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Kavu+Titan) を Kicker でサモン。小野田はその返しに [Yawgmoth's Agenda](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Yawgmoth%27s+Agenda) をキャストし、Lau のアップキープに 5/5 の Titan へと [Terminate](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Terminate) をキャスト。Lau はこれを [Repulse](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Repulse) で守ることを選んだ。小野田は続くターンに [Thunderscape Battlemage](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Thunderscape+Battlemage) を Kicker で召喚して Lau に 2 枚のハンドを捨てさせたのだが、このクリーチャーも即座に [Urza's Rage](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Urza%27s+Rage) されてしまった。Lau は [Kavu Titan](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Kavu+Titan) を Kicker で召喚しては小野田の墓地の [Terminate](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Terminate) を消費させていき、[Crypt Angel](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Crypt+Angel) もキャストを許したものの即座に [Repulse](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Repulse) してみせた。そうこうするうちに Lau のサイドには [Kavu Titan](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Kavu+Titan) with Kicker と [Blurred Mongoose](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Blurred+Mongoose) が現れたのだった。

小野田は Battlemage と Mongoose を相打ちにさせると、[Phyrexian Rager](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Phyrexian+Rager) をサモン。さらに再度 [Crypt Angel](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Crypt+Angel) を召喚して [Thunderscape Battlemage](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Thunderscape+Battlemage) を回収した。 ・・・そのまま Sam Lau には [Crypt Angel](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Crypt+Angel) を対処しうるカードは恵まれず、Lau は投了を余儀なくされたのだった。

小野田倫久 1-0

### Game 2

![](https://media.magic.wizards.com/image_legacy_migration/sideboard/images/GPSING01/971.jpg)

先攻を選んだ Lau がテイクマリガン。 今度はランドはあるものの"Bear"がいないという立ち上がりだった。一方の小野田は [Shivan Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Shivan+Zombie) を連打したのだが、2 枚目のほうは [Exclude](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Exclude) されてしまったのであった。それでもライフで先攻したのは小野田である。とにかくクリーチャーに恵まれず、ランドも 3 枚でストップしてしまった Lau は [Repulse](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Repulse) した上で再召喚された [Shivan Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Shivan+Zombie) に [Urza's Rage](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Urza%27s+Rage) を使わざるを得なかったのだった。小野田の [Crypt Angel](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Crypt+Angel) を [Exclude](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Exclude) したに及んでようやっと待望の 4 枚目のランドを入手し、小野田の [Pyre Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Pyre+Zombie) を [Mystic Snake](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Mystic+Snake) しできたのであったが、これも小野田によって即座に [Slay](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Slay) されてしまったのだった。

![](https://media.magic.wizards.com/image_legacy_migration/sideboard/images/GPSING01/970.jpg)

小野田が Skyfolk を除去すべく召喚した [Flametongue Kavu](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Flametongue+Kavu) が返す刀の Lau の [Flametongue Kavu](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Flametongue+Kavu) で除去され、その Kavu も小野田の [Ghitu Fire](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Ghitu+Fire) によって除去された。これによって場は一掃され、新たな脅威の召喚合戦の結果として Lau の 2/2の [Kavu Titan](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Kavu+Titan) と小野田の [Skizzik](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Skizzik) が殴り合うという甚だ不平等な展開となり、さらに、小野田の [Pyre Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Pyre+Zombie) がマナの充実ともに場を支配し始めた。 Lau は [Prophetic Bolt](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Prophetic+Bolt) を [Pyre Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Pyre+Zombie) に打ち込むなどして挽回をはかったが、もはや悪あがきとしか言いようがなくなってしまったようだ。

・・・まもなく、[Pyre Zombie](https://web.archive.org/web/20000101000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Pyre+Zombie) が傷口を致命傷にかえたのだった。

小野田倫久 2-0
