Like rewards for playing tournament **Magic**? Coming to a [Magic Player Rewards](https://web.archive.org/web/20031117000000/http://www.wizards.com/dci/rewards.asp) program near you: new creature token cards. The next upcoming batch of tokens available through the program will be an Angel token (for use with *Scourge's* Decree of Justice) and a Pentavite token (for use with *Mirrodin's* Pentavus). Check out the art for both of these upcoming token cards. 

See also this [previous Magic Arcana](/en/articles/arcana/2003/09-24-the-new-look-of-tokens) to see how these creature tokens look in the new card frame.
