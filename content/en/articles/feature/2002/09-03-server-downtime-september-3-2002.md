### List of Changes

* * *

### Gameplay

*   Prompt appears if a player clicks **OK** and would receive mana burn.
*   Assigned damage numbers appear on creatures and players when card dealing combat damage is moused over.
*   **Landswap** has been replaced with **Add Lands** in the Sealed Deck **Deck Builder** screen.
*   Lands can be added to any sealed deck (team or single player) during deck building and sideboarding.

### Game Formats

*   Support for more limited formats, including *Seventh EditionTM* Sealed Deck and leagues.
*   A new **Options** button appears when starting a game. This button opens a new window where the options available depend on what type of game you're setting up.

### Casual Games

*   Many new casual event options. See the **New Game Options** section of help for a detailed description.
*   New games allow starting handicaps (reduced life total and/or starting hand size).
*   New **Event Timer Options** drop down list allows you to choose how long each game in the event will be.
*   New shared **Deck Builder** screen option for team Sealed Deck events.

### Multiplayer (includes all other Casual Games changes)

*   Many new game options. See the **Multiplayer Options** section of help for a detailed description.
*   Option to allow players to choose the opponent to attack, instead of attack-left only. (Not available for Emperor events.)
*   New **Maximum spell range** option and ability to limit the players who can target spells or abilities on the stack. (Emperor only.)

### Leagues

***NOTE: These changes will not affect any leagues that began before the Sept. 3rd update.***

*   Many changes to new leagues. See the **Leagues** and **League Prizes** sections of the help for a detailed description.
*   Players can play against a specific opponent for league points only two times per league. (Players aren't limited on number of tiebreaker matches versus an opponent.) This limit is not imposed on no-prize leagues.
*   New league prize table. See the **League Prizes** section in help for more information.
*   League match wins now award 2 points for a win, 1 point for a loss, and 1 point for a draw.
*   Tiebreaker match wins now award 2 points for a win, -1 point for a loss, and 0 points for a draw.

### Interface

*   New **My Leagues** window shows league status and gives players quick access to league deck editing, statistics, and game play for each league you're in.
*   The interface remembers your preference for visual or spreadsheet mode when switching rooms.
*   Pressing Enter works as **OK** in popup dialog boxes.
*   Pressing Esc works as **Cancel** in popup dialog boxes.
*   Leagues you're in are highlighted in the **Leagues** room.
*   Popup text lets you see what type a creature was before having its type changed (via Unnatural Selection, Dralnu's Crusade, etc.).
*   **Net Decks** window now has a **Delete** button.
*   Modified column positions in room spreadsheets are preserved when updates are received.
*   "Game not available" message bug fixed.
*   Clan can now have 20 players (instead of 10).
*   **My buddies** and **Blocked user** lists maximum sizes are now 100 (instead of 50).

### Other Changes

*   When trading cards, if either player removes or adds a card to the "You get" or "You give" pile, the pile scrolls to show the added card or the position of the removed card.
*   Changed the number of packs awarded from each set in eight-player sanctioned tournaments.
*   Sanctioned constructed events now award packs from more than one set.
*   Fixed multiplayer library search problem (when the searching player leaves the game before searching).
*   Fixed a crash bug that occurred when a player concedes during the resolution of a Wish spell in a multiplayer game.
*   Fixed a crash bug that occurred when a player clicked on a scroll bar in the **Deck Editor** and pressed a key.
*   Fixed the direction of Faceless Butcher arrows.
*   Fixed the Wish ability to target a card in the sideboard but not in the collection.
*   Fixed a typo in the stack tutorial.
*   Many help files updated to include new features, changes to features (from both this update and the previous update), and to fix some reported bugs.

### Card Rules

*   Honorable Scout works properly with Alter Reality.
*   Thorn Elemental damage assignment works if the blocking creature is no longer controlled by the player.
*   Phantom Nantuko message no longer asks players to remove counters when none remain.
*   Teferi's Response works correctly with Petravark's ability.
