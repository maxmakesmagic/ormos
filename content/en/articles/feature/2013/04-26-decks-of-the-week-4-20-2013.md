Prereleases for *Dragon's Maze* occur this weekend! If you didn't preregister for a nearby Prerelease, you might still be able to find one with availability by using the [event locator](https://web.archive.org/web/20130426000000/http://locator.wizards.com/). This season's PTQs and WMCQs run the Standard format, and we will have Top 8 decks from them all season so you can see what's going on in the metagame, including how *Dragon's Maze* shakes it up. Find the nearest PTQ to you with [this handy link](/en/articles/event-coverage/2012/02-24-pro-tour-qualifier-list#theros)! Good luck; have fun!
