* * *

For anyone just tuning in, we've had some serious issues with ***Magic** Online* since the beginning of March. Part of the resolution to our problems was to move code from the beta server to the live server. We brought in some extra help at the beginning of February to see what could be done about cleaning up the 2.0 server code. They had made a good deal of progress by the time the crashes began, so we decided to see how that code held up by bringing everyone over to the beta server for a while. And, while we had some initial issues, that code turned out to be much more stable than the live code. So we pushed the code they had been cleaning up over to the live server.

Since bringing the code over, we've been slowly turning functionality back on. As of Wednesday, March 17, here's where we are:  
  

*   Besides one planned downtime on Monday, ***Magic** Online* has been stable for about four days.  
  

*   The 8-player draft and Constructed queues are up and firing.  
  

*   The *Darksteel* set has been added to the game and is part of regular draft queues.  
  

*   *Darksteel* cards will be legal in Constructed queues on March 22.  
  
 You can read through my posts in the [Announcements folder of the message boards](https://web.archive.org/web/20040317000000/http://boards1.wizards.com/forumdisplay.php?s=&forumid=217) for all the nitty-gritty details.

The next item we need to tackle is a big one: starting leagues back up. As it turns out, the bug that crashes leagues and premier events is either the same or closely linked. It affects both regular and release leagues, but the strain of release leagues exacerbates the problem and makes it more obvious. 

This doesn't mean we're removing leagues permanently. Restoring league functionality is the dev team's top priority right now, but it's going to take some time. How much? We don't know yet. I'm hoping the dev team has more details I can pass on to you for my column next week.

As things stand, there isn't going to be much to report on until the dev team nails down the bug and starts testing fixes for it. From here on out, most of the news about our progress will come through my Tuesday column on [**magicthegathering.com**](https://web.archive.org/web/20080725102347/http://wizards.com/magic). I'm still getting some answers about outstanding issues, so I'll either put them into the column or drop a note in the [Announcements folder](https://web.archive.org/web/20040317000000/http://boards1.wizards.com/forumdisplay.php?s=&forumid=217).

I'm sorry it's taken this long to get to this point in fixing ***Magic** Online* and that bringing back leagues is going to take more time. Thanks for all your patience. Keep an eye on the Announcements folder for any breaking news and make sure to check my weekly column for details on what's going on inside ***Magic** Online*.

-Dan
