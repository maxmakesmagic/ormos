While a **Magic** set is being created, it's not uncommon for a card's rules text to change, which can impact flavor text. Re-worded rules text and added reminder text can crowd out those italicized gems o' wisdom, so occasionally even brilliantly-written flavor text, sadly, has to go. 

But sometimes that flavor text gets rescued.

Darksteel Ingot, for example, originally had the following flavor text:

Clearly the Ingot already has a lot of rules text on it -- the flavor text got the boot. But if that Pontifex quote sounds familiar, it's because it ended up on Darksteel Forge. What a save!
