In Wizards of the Coast's internal database, Multiverse, cards are labeled by codes that identify the card and describe its sort order in a given set. The numbering system is the same from set to set-it includes codes for the card's rarity and color, and an ID number. The codes are ordered in the same way every set, too-they run in WUBRG order, then by rarity, then by ID number. Therefore, the first card in the set's Multiverse "file" always has the same code number, and is always a white common card. For example, the card with the first code in Alpha is Benalish Hero. In the *[Planar Chaos](https://web.archive.org/web/20070123000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Planar+Chaos)* set, it's Whitemane Lion.
