M***agic** 2010* is only a few weeks away. If you play in the prerelease (July 11-12), you'll get this:

![](https://i.ormos.uk/8b/a8/8ba8bd83a9ac101899727e3ab5baaa6bdcaeaa5c8efaf0d5aee2168a651003f1.jpg)

And if you play in a [Launch Party](https://web.archive.org/web/20090630000000/http://archive.wizards.com/magic/magazine/article.aspx?x=mtgcom/events/releases) (July 17-19), you'll get *this*:

![](https://i.ormos.uk/e3/c6/e3c608d69fa56caeb3eda7d9e637e345df7b3482f7ce123a007b4e346906c913.jpg)

There are, of course, versions in other languages. But before we show those off, how about today's update of Core Set Survivor?

  
  
**Core Set Survivor!**

There are exactly sixteen cards that have been in every core set from *Alpha* to *Tenth Edition*. When ***Magic** 2010* comes out, only *eight* cards will have been in every core set. Over the weeks before the ***Magic** 2010* prerelease, we'll be counting them down in this special Arcana sub-feature, giving you an "IN" or "OUT" on one card a day. Step forward, [Howling Mine](https://web.archive.org/web/20090630000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Howling+Mine).
