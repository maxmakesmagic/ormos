**How can you get this booster?**

Every *8th Edition* Core Game contains a unique code. You will find this code on a sticker in the rulebook included in the game. Send us this code and we’ll make sure you’ll receive a free *8th Edition* booster.

![](https://i.ormos.uk/03/82/0382adc15b02eb36858af4171c73db7a28e26fdf175c3e7278498c51f10dc2a0.jpg)

As you can see, participating is easy. If you haven’t bought the Core Game yet and would like to know more about the game, check out our special [*8th Edition* pages](https://web.archive.org/web/20050103084452/http://www.wizards.com/default.asp?x=magic/academy/welcome). 

If you want to learn to play the game online, [click here](https://web.archive.org/web/20050114013749/http://www.wizards.com/magic/playbig.asp).

If you already have the Core Game and you’re eager to get the booster as well, don’t wait any longer and [register here.](http://www.coregamepromotion.com/en/index.html)
