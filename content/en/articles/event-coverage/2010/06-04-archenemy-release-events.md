*Archenemy* Release Events are a great way to experience and celebrate the release of the newest way to play multiplayer **Magic** – *Archenemy*! All participants receive a Plots That Span Centuries promo scheme card (while supplies last).

### Release Event Format

*   Each player will receive one of the four *Archenemy* Game Packs. The game pack contains a 60-card **Magic** deck and a 20-card scheme deck.
*   *Archenemy* Release events will use an open play format. Players will be placed into game groups of 3-5 players. When a game finishes, players can play again or be regrouped into another game with new players.
*   Each player will receive a Plots That Span Centuries promo scheme card (while supplies last).
*   Contact your local Release Event Organizer for event information.
