Mono-Blue Devotion is dead.

  

![Ephara, God of the Polis](http://gatherer.wizards.com/Handlers/Image.ashx?type=card&name=Ephara%2C+God+of+the+Polis)

If you've been paying attention, Mono-Blue Devotion hasn't been putting up great finishes ever since *Born of the Gods* was released. Nearly every deck out there received some nice upgrades except for Mono-Blue. As a result, Mono-Blue stopped putting up the numbers that it did pre-BNG. 

What the archetype needed is a boost that would allow it to keep up with the other archetypes. As DaveLombardoJr discovered, splashing white for [Ephara, God of the Polis](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Ephara%2C+God+of+the+Polis) and [Detention Sphere](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Detention+Sphere) is probably what the deck needed. Ephara allows the deck to clean up the [Bident of Thassa](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Bident+of+Thassa)/[Jace, Architect of Thought](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Jace%2C+Architect+of+Thought) splits the Mono-Blue versions used to play. Similarly, [Detention Sphere](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Detention+Sphere) cleans up the [Cyclonic Rift](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Cyclonic+Rift)/[Rapid Hybridization](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Rapid+Hybridization) slot. It also deals with multiple [Pack Rat](https://web.archive.org/web/20140311000000/https://gatherer.wizards.com/Pages/Card/Details.aspx?name=Pack+Rat)s, which was always an issue. 

Most of the time, all a deck needs is a little fine tuning in order to be successful. Long live WU Devotion?
