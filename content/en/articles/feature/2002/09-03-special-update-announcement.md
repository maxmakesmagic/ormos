### Note About the September 3rd Update

* * *

Today's scheduled maintenance included several new and exciting enhancements to the game. We are going to keep the system in "No-Pay" mode for several hours while we give the system a thorough shakedown.

"No-Pay" mode means that no events that require Event Tickets will be run during this period. This includes any events in the **Leagues**, **Sanctioned Tournaments**, and **Premier Events** rooms.

For information on when you'll be able to begin playing in these events, keep an eye on [this message board thread](https://web.archive.org/web/20020903000000/http://wizards.com/leaving.asp?url=http://boards.wizards.com/tcg/ultimatebb.php?ubb=get_topic;f=113;t=000028&origin=magic_magiconline_septupdate).
