**Aufmarsch Hintergrundbilder**

Installation auf einem Mac:  

*   Drücke "Control" + Klick
*   Wähle "Download Bild auf Festplatte"
*   Gehe zu "Kontrollfelder" (Apple-Menü)
*   Wähle "Erscheinungsbild"
*   Klicke auf "Schreibtisch"
*   Klicke auf "Bild positionieren"
*   Klicke auf "Übernehmen"

Installation auf einem PC  

*   Rechtsklick auf das Hintergrundbild im Browser
*   "Als Hintergrundbild" auswählen

**Hier für PC klicken**  
**Hier für MAC klicken**  

**Aufmarsch Bildschirmschoner**

Installation auf einem MAC (OS8.6-OS9.2):  

*   Den Bildschirmschoner auf den Desktop herunterladen
*   Entpacken
*   Verschiebe den Bildschirmschoner in den Ordner "Kontrollfelder" im Apple-Menü

Installation auf einem PC:  

*   Das zip Archiv auf der Festplatte speichern und entpacken
*   Die Datei Doppelklicken
*   Die Installation started automatisch
