Couldn't make it out to [Grand Prix Las Vegas](https://www.grandprixvegas.com/) for the Planeswalker Deck Preview Event? Thinking about heading to an Open House (where, psst, you can buy these, even before *Core Set 2019* is fully released!)? Well, check out what the five Planeswalker Decks from *Core Set 2019* have in store for you.

Not sure what some of these cards do? Cards newly revealed today are below. For everything previously revealed, check out the [*Core Set 2019* Card Image Gallery](/en/articles/card-image-gallery/2018/06-22-core-set-2019) and the [Packaging and Promos article from Monday](/en/articles/card-preview/2018/06-11-core-set-2019-packaging-promos-and-more).
