### List of Changes

* * *

![](http://wizards.com/global/images/magic_magiconline_tufix100102_pic1_en.jpg)

The Seventh Annual **Magic: The Gathering®** Invitational will be held October 18-20, 2002 in Seattle, WA. In the **Magic®** equivalent of the all-star game, sixteen top players from around the world will compete for the opportunity to design his own **Magic** card. And this year, for the first time, the entire competition will take place on ***Magic** Online.* You'll be able to watch replays of all the games and play against the competitors in special "gunslinging" rooms. Watch the ***Magic** Online* web site for more information.

### Invitational

*   **Magic** Invitational events layout added to the interface.
*   *SideboardTM* logo links to the *Sideboard* Online web site.
*   **Magic** Invitational logo links to the *Sideboard* Online web site coverage of the events.
*   **Invitational** room game play is restricted to Invitational accounts only (except **Gunslinging** rooms).
*   Non-Invitational players will be able to start games in the **Gunslinging** rooms on Sunday, October 20. Only Invitational players will be able to join the games.
*   Rochester Draft tables in the **Invitational** area list options for replaying all finished games and the draft portion itself when players click on the table.
*   Players can replay Invitational games by clicking on the table where a game took place. Clicking the table opens a menu listing all finished games.
*   Replays of finished Rochester Draft and 2-Headed Giant games in **Invitational** rooms show each player's hand.
*   Administrators can enable **Gunslinging** rooms when the Invitational players are ready to play games in them (Sunday, October 20).

### *Onslaught*

*   The official ***Magic** Online* release of the *Onslaught* set is scheduled for November 1, but as of this update you can view *Onslaught* cards on the **Collection** screen. As with all cards you don't own, set **Number owned** to **&gt;= 0** to view *Onslaught* cards.
*   You can view face-down creatures you control during a game by pressing F5. Cards flipped over using F5 will automatically flip back over in a couple of seconds. **Note:** This is **not** the same as paying the morph cost to turn over a face-down creature.
*   The terms "morph," "cycling," and "fear" now appear shaded on the card display areas of screens. Click the shaded terms to open a pop-up definition window. **Note:** If you don't have **Shade keywords and show definitions** selected on your **Display Settings** screen, you won't see these or any other keywords shaded.

### Interface

*   Two new avatars: Erhnam Djinn and Serra Angel.
*   **Sort by creature type** option added to the **Deck Builder** screen.
*   A card's type is now included when searching for matching text.
*   Various reported text bugs fixed.
*   Triggered effects window appears in a better location initially.
*   The name of the currently loaded deck is cleared from the **Deck Editor** screen when you click **New Deck**.
*   Decks with lands added using the old **Landswap** button now load correctly.
*   The **New Game Options** window remembers the settings you selected the last time you set up a game (even if you cancelled the game instead of starting it).
*   Column headers in the **My Leagues** window have been relabeled.
*   Artist credits on tokens use the same font size as the creature type text.
*   The card search filter on shared **Deck Builder** screens affect all players' **Sideboard** windows.
*   The oldest copy of a card in your **Collection** will be traded first (when set for trade).
*   Saved decks from **Sealed Deck** events are named differently.
*   The **/away** command prints your away message in any group or clan chat windows you have open.
*   Preconstructed decklists are linked to the local PC (not Elaine's).
*   Cards with names beginning "Æ" are now alphabetized correctly.
*   **Choose a creature type** window has a shorter list with the most common creature types at the beginning.
*   You can type the name of a creature in the **Choose a creature type** window to go directly to that creature type.
*   Items on the stack that are copies of other items on the stack have a special "copy" icon in the upper left corner.
*   The **/info** *playername* command brings up that player's **Player profile** window. Type **/info** "*player name*" for names with spaces in them.
*   Online Extended format added to the **Deck Editor** and **Collection** screen on the **Sets** pull down menus.
*   Colorless permanents now use a generic gray frame instead of the artifact frame.
*   Problem showing player scores in busy draft rooms fixed.
*   Players can replay Invitational games by clicking on the table where a game or draft took place. Clicking the table opens a menu listing all finished games and, in Rochester Drafts, the draft itself.
*   Casual timed games keep track of game options and remaining time when adjourned.
*   Improved functionality reduces the chance a player that loses connection will be paired up in a 8-player room or league.
*   Option to turn off mana burn warning added to **Game Play Settings**.

### Gameplay

*   Problem with using F2 when you have a chat window open fixed.
*   F4 now bypasses the mana-burn prompt along with yielding priority for the turn.

### Leagues

*   Player pairing revised and improved-please try it out for a while and let us know how it works.
*   Error in number of recent matches shown in the **My Leagues** window fixed.
*   **Waiting for players** window stays visible instead of minimizing if you click **Edit Deck** while the window is open.
*   Cards from the most recently added booster have a light blue highlight around them.
*   Chat input box removed from the **Waiting for players** window.

### Multiplayer

*   Error caused when Wild Mongrel's ability is on the stack and it's controller leaves the game fixed.
*   Error caused when Protective Sphere's ability is on the stack and it's controller leaves the game fixed.

### Text Changes

*   Mist of Stagnation prompt text now explains that you can untap permanents controlled by other players.
*   "This" correctly capitalized when it appears as an abbreviation in card text.

### Card Rules

*   Selfless Exorcist and Unquestioned Authority now work correctly together.
*   Resolution of Teferi's Response played in response to Petravark coming into play corrected (Petravark is destroyed).
*   Error caused by discarding Obsessive Search during the clean-up step fixed.
*   Resolution of playing a card from the graveyard using it's flashback ability in response to it being targeted by Gravegouger corrected (the controller doesn't get the card back when Gravegouger leaves play).
*   Naming a split card when playing Cabal Therapy works correctly.
*   Lobotomy now reveals players' hands (Oracle ruling).
*   Cephalid Shrine doesn't prompt for "garbage" mana to pay for {X}.
*   Cards that reveal players' hands (Seer's Vision, Telepathy, etc.) work properly in both replays and watched games.

### Other Bug Fixes

*   Long descriptions in spreadsheet view of rooms aren't cut off when the room updates (a new event begins, a round ends, etc.).
*   Cards don't move as slowly from one zone to another. (Appeared in version 1.0.970.)
*   Automatic deck creation fixed for team Sealed events when players don't submit a legal deck within the time limit.
*   Teams who don't submit decks within the time limit in Rochester Draft events are no longer ejected from the event.
*   Players can't type active links in **Private chat** windows using the **/away** command.
*   Decks with lands added using the old **Landswap** button now load correctly.
*   Fixed "garbage names" problem with long player names in windows opened from your **My buddies** window.
