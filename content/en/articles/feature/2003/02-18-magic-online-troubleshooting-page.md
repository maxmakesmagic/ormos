### System Requirements

**Minimum System Requirements** In order to run ***Magic** Online,* your system must meet the following minimum requirements: 

*   Windows® 95/98/2000/Me/XP or Windows NT® 4.0
*   Pentium® II 333 MHz (or equivalent)
*   64 MB RAM
*   600 MB free hard disk space
*   A video card able to handle 800 x 600 pixels and Hi Color settings
*   DirectX® 3.0 or higher
*   4X CD-ROM drive
*   A sound card
*   An Internet connection (56 K or better)
*   A Web browser that supports SSL encryption (most browsers do)

**Recommended System Requirements**

*   Windows® 98/2000/Me/XP
*   Pentium® II 333 MHz (or equivalent)
*   128 MB RAM
*   1 GB free hard disk space
*   A video card able to handle 1024 x 768 pixels and Hi Color settings
*   DirectX® 3.0 or higher
*   4X CD-ROM drive
*   A sound card
*   A high speed Internet connection (DSL, Cable Modem, or ISDN)
*   Internet Explorer 6.0

### Internet Connection

You must be connected to the Internet in order to install and update ***Magic** Online.* If you have problems staying connected to the servers during installation, updating, or game play, please contact your ISP for assistance.

Please read the Terms of Service for ***Magic** Online* carefully before agreeing to them and entering the game. If you have any questions regarding the Terms of Service for ***Magic** Online,* contact Wizards of the Coast [Technical Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/tspage&origin=magic_magiconline_troubleshoot).

### Problems Installing *Magic Online*

The first thing you need to do is make sure you're connected to the Internet while installing ***Magic** Online.* If you are installing from the downloaded version (not on CD), first check that you are downloading ***Magic** Online* from one of the official download sites listed on the [***Magic** Online* Download page](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/downloadlinks&origin=magic_magiconline_troubleshoot).

If you've already downloaded the file, it should be called **MTGODL2.EXE** and be exactly 205,996,544 bytes (196MB). To ensure the file you downloaded is complete: 

*   Right-click the file **MTGODL2.EXE** and select **Properties**.
*   In the pop-up window, you should see **Size: 196MB (205,996,544 bytes)**.

If this isn't what you see, then the file may be corrupted. Either retry the download, or contact the download site to determine what went wrong.

Also, before downloading ***Magic** Online,* make sure that nothing except your Internet connection is running in the background.

To make sure there are no other programs running in Windows 9x/ME: 

*   Hold down the CTRL and ALT keys and press the DEL key. This will bring up a **Close Program** box. The **Close Program** box will show the currently running programs.
*   The only programs you want listed in the task list are Explorer and Systray (if you have it). If there are other programs in the task list, highlight one of them and click **End Task**.
*   Repeat steps 1 and 2 until the only programs listed in the **Close Program** box are the Explorer and Systray. **NOTE:** Some programs cannot be shut down using these steps. You will need to shut down those programs according to the instructions specific to those programs.
*   Once the Explorer and Systray are the only programs in the **Close Program** box, connect to the Internet and try downloading the program again.

To make sure there are no other programs running in Windows 2000/XP Professional: 

*   Hold down the CTRL and ALT keys and press the DEL key. This will bring up a **Windows Security** window.
*   Click **Task Manager**.
*   In the Windows Task Manager click the **Applications** tab.
*   You want to make sure no applications are listed. To close the application, select the application in the list then click **End Task**. Repeat this until no applications are listed.
*   Connect to the Internet and try downloading the program again.

If you have problems downloading from Gigex, IGN, or Gamespot, use the Fileplanet download without using a download accelerator.

Remember, ***Magic** Online* is a large download, and over a 56k modem will take quite some time.

### Error Messages

**Couldn't resolve address http://...**  
 If you are getting this error while opening the **tos.txt** file, you are completely unable to connect to the servers. Whether or not this error is appearing for the **tos.txt** file or some other file, here are the issues that might be causing this problem: 

*   [Internet Connection](#Connection_Issues)
*   [Anti-virus Software](#Anti-virus)
*   [Proxy Server](#Proxy)
*   [Firewall](#Firewall)
*   [Windows Internet Connection Sharing](#Connection_Sharing)

**Lost connection before entire file contents...**  
 This error means that you are able to talk to the servers, but something is wrong with your connection. The first thing you can do is to re-try updating or reinstalling. Perhaps it was just a small hiccup with your connection that will resolve itself. If that doesn't work, here are the issues that might be causing this problem: 

*   [Anti-virus Software](#Anti-virus)
*   [Proxy Server](#Proxy)
*   [Firewall](#Firewall)
*   [Windows Internet Connection Sharing](#Connection_Sharing)

**Missing \[filename\] or a \*.PNG file error**  
 This error means you need to update your software. 

*   Close ***Magic** Online* and restart it.
*   On the ***Magic Online* Install/Update Agent** screen (the one with the Shivan Dragon on it) select **Scan All Files**.
*   Click **Launch**.

**Checksum Errors**  
 This error means that you are missing a file necessary for ***Magic** Online* to function or that a file has been corrupted. 

*   Close ***Magic** Online* and restart it.
*   On the ***Magic Online* Install/Update Agent** screen (the one with the Shivan Dragon on it) select **Scan All Files**.
*   Click **Launch**.

### Connection Issues

**Browser Download Test**  
 Try downloading the file you got the error on using your Internet browser.

*   Type the address of the file into your browser's address field.
*   Press Enter.

For example, if you want to download the **tos.txt** file, type: **http://mtgodownloads.wizards.com/mtgo/tos.txt** into your browser's address window and press Enter.

If you can't download the file using your browser, then recheck your [proxy](#Proxy) information.

If you can download the file using your browser, try installing or updating ***Magic** Online* again. There might've been a connection problem that has corrected itself. If it still fails to install or update after you verify that you can download the file using your browser, contact [Technical Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=default.asp?x=magic/magiconline/tspage&origin=magic_magiconline_troubleshoot).

You can also try launching **magic1.exe** from the directory (folder) where you installed ***Magic** Online.* This executable doesn't require a connection to our servers before launching. As long as you have updated recently, you should be able to login to the game and play just fine. If this succeeds, try launching the game as you normally would the next time you play. If you continue to experience problems, then please contact [Technical Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=default.asp?x=magic/magiconline/tspage&origin=magic_magiconline_troubleshoot).

**Anti-virus Software**  
 If you have anti-virus software installed on your PC, make sure you disable it before attempting to install ***Magic** Online.*

**NetNanny® Software**  
 Sometimes using ***Magic** Online* software in conjunction with **NetNanny** software causes irregular errors. In order for ***Magic** Online* to work correctly with **NetNanny,** add the following to the **NetNanny** "allowed" list: 

*   mtgoinstall.wizards.com
*   mtgodownloads.wizards.com
*   www.wizards.com

**Proxy Servers**  
 Sometimes, even though you aren't using a proxy server, your Internet Service Provider (ISP) might be. If you're having trouble connecting to the ***Magic** Online* server, try these steps: 

*   On the ***Magic Online* Install/Update Agent** screen (the one with Shivan Dragon on it), click **Settings** to open the **Connection Settings** window.
*   Click **Detect**.
*   If your web browser is already configured to use your proxy information, the software will detect this information automatically, fill in the server name and port, and select **Use Proxy Server Settings** for you.
*   If your web browser isn't configured to use your proxy information, you need to contact your ISP to get your proxy settings.
*   If you're using a proxy server that requires you to login, select **My proxy server requires me to login**. When you do, the **Proxy Authentication** sub-menu will appear. Enter your username and password in the appropriate fields.

**Firewall**  
 If you're on a network at work, you are likely behind a security firewall. To play ***Magic** Online* through a firewall, the following ports must be opened: 

*   9896
*   16000-16999

If you're on a network with a firewall, your network administrator will probably have to open these ports for you.

If you want to use the Windows XP built-in firewall software you'll need to open the ports listed above. If that doesn't work, you can try disabling the Windows XP firewall.

**Bull Guard®** and **Zone Alarm®** are both firewall programs that have had problems with ***Magic** Online.* If you are using either of these programs and opening the ports listed doesn't work, you may need to disable the software.

**Windows Internet Connection Sharing**  
 There is a problem with Windows Internet Connection Sharing that sometimes causes dropped connections. Following the procedure at: [http://www.annoyances.org/exec/show/article04-107](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=http://www.annoyances.org/exec/show/article04-107&origin=magic_magiconline_troubleshoot) has fixed this problem for many players who have home networks or use Internet Connection Sharing.

Finally, you will want make sure that you have the latest drivers for your modem. Check with your modem manufacturer and/or your Internet Service Provider to confirm that you have the latest drivers installed.

### Video and/or Sound Issues

These issues can include sounds not playing, a black screen or video distortion, or missing graphics within ***Magic** Online.*

An outdated driver or a driver conflict can cause issues with the video and/or sound in ***Magic** Online.* Contact the manufacturers of both your sound and video cards for the latest drivers for your hardware. Many manufacturers update their drivers every three months. Updating your drivers usually eliminates conflicts, expands features, increases stability, and will include application-specific bug fixes that the manufacturer chooses to address.

To identify the hardware/update the drivers: 

*   Right-click the **My Computer** icon on your PC desktop.
*   Select **Properties** from the menu that appears.
*   Click the **Device Manager** tab.
*   Click the "+" symbol in front of **Display adapters** (the name of your video card should appear).
*   Click the "+" symbol in front of **Sound, video and game controllers** (the name of your soundcard should appear).
*   Write down the type and model of the cards.

Now you can go to the card manufacturers' websites. If you don't know their exact web addresses, the following site has most card manufacturers' websites listed:  
[http://www.winfiles.com/](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=http://www.winfiles.com/&origin=magic_magiconline_troubleshoot)

Next, go to the **Drivers** section of each card manufacturer's website. Then select and download the most current driver for your card for the version of Windows (95, 98, XP, etc.) installed on your computer. You will want to follow the manufacturers instructions on how to install these updates since they will be specific to your particular hardware we won't have instructions for you.

Alternatively, you can contact the system vendor for recommendations on where to go to obtain drivers for your hardware.

### Account Problems

**What does a "Bad Username or Password" message mean?**  
 A "Bad Username or Password" message indicates one of the following:

*   You have forgotten or mistyped your password. Remember, passwords are case-sensitive. Make sure that your CAPS LOCK is off when you are entering your password.
*   Your account has been deactivated as part of an investigation by the ***Magic** Online* team. This can be verified if you follow the [below directions for retrieving your password](#Forgot_password) and you receive a message stating that you have not set a security question. [Contact Technical Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/tspage&origin=magic_magiconline_troubleshoot) for assistance.
*   Your account has been deactivated or banned by an Adept within the game or by Community Support. You will receive either an in-game message or e-mail if this is the case. [Contact Community Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/comspage&origin=magic_magiconline_troubleshoot) for more information on reactivating your account.

If you have forgotten or would like to reset your password, please go to [http://magiconlinestore.wizards.com/forgotpassword.asp](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=http://magiconlinestore.wizards.com/forgotpassword.asp&origin=magic_magiconline_troubleshoot) and follow the onscreen instructions. You will then be emailed a new password.

To change your password, you need to be logged into ***Magic** Online.* Click **Settings**, select the **Account** tab, then click **Change Password**. Follow the onscreen instructions and your password will be changed to one of your choosing.

**I did not receive the cards I ordered or a prize I won. What do I do?**  
 If you do not receive your product within 24 hours of placing the order, [contact the ***Magic** Online* Store](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/sspage&origin=magic_magiconline_troubleshoot). Include the order number or copy of the order confirmation from your e-mail.

If you do not receive a prize within 24 hours of the end of the tournament you played in, [contact Technical Support](https://web.archive.org/web/20030218000000/http://www.wizards.com/leaving.asp?url=/default.asp?x=magic/magiconline/tspage&origin=magic_magiconline_troubleshoot). Include the tournament ID number, your username, and the date and time of the tournament.
