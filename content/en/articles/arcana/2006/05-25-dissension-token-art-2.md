The *Dissension* release for ***Magic** Online* is right around the corner! The set features four new pieces of art commissioned for the latest crop of token-generating cards. So, while you drool at the prospect of picking up your Momir Vig and Lyzolda avatars (see [Bennie Smith's article today](/en/articles/intotheaether/2006/05-25-mtgo-iii-news-and-more) for more on those), here's an exclusive look at the new token menaces you'll be summoning up shortly. 

  
  

![Snake token art](https://i.ormos.uk/ee/1b/ee1b8269db7500da8949a5ac2993e4d7cb645dfccc098e1c14436453e33a79bd.jpg "Snake token art")  
*Dissension Snake token art (for Patagia Viper) by Christopher Moeller*

![Drake token art](https://i.ormos.uk/5e/3f/5e3f61a8151298a2ade0b5e10614a2e5deff23a093506cdd3a15fd977dbd49dc.jpg "Drake token art")  
*Drake token art (for Leafdrake Roost) by Nick Percival*

![Wurm token art](https://i.ormos.uk/87/e8/87e8963f54bc5eec9863c17cb7b7a81970c3f1216d0cabdbef0ae3c43d6ca31e.jpg "Wurm token art")  
*Elemental token art (from Development, of Research/Development) by Greg Staples*

![Wurm token art](https://i.ormos.uk/5b/55/5b556286efdcf7a05bb00e9ac989aa8cf7a44d9f3cfe8616759462ab4b391862.jpg "Wurm token art")  
*Bird token art (for Pride of the Clouds and Dovescape) by Shishizaru*

*Dissension* goes on sale May 30th for ***Magic** Online*, and release tournaments start up June 1st, so you'll be swinging in with your own copies of these creatures in no time. See you then!
