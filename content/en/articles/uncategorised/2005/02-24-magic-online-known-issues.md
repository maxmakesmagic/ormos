### General Topics

**Topic: Card Count Issue in Graphical Deck Builder**

Issue: Card count is reported incorrectly when adding a card that exists in multiple sets or has multiple versions (foil & standard)

Notes: When using the graphical collection view, a user can double click a card to add it to a new deck. If that card exists in multiple sets or has multiple versions (regular & foil) the number of cards the user has in his collection is decremented for all sets and/or all versions

Expected Behavior: Card count should only be decremented by 1

**Topic: Distorted Effect Arrow**

Issue: Effect arrows may become distorted when scrolling over an image if the card in the stack area.

Expected Behavior: Arrows should not become distorted

### *Fifth Dawn*

**Topic: Grafted Wargear & Guardian Idol**

Issue: Triggered abilities resolve but clean upstep does not restart

Expected Behavior: Triggers that happen during cleanup should resolve, then cleanup step should restart.

**Topic: Neurok Transmuter, March of the Machines, Mycosynth Lattice** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: When March of the Machines and Neurok Transmuter is played on Mycosythn Lattice the type line on Mycosynth Lattice reads Tblk17.tga 

Expected Behavior: Mycosynth Lattice's type line should be blank. 

**Topic: Rain of Rust**

Issue: When you entwine Rain of Rust and the option to choose a land appears. Some of the cards are not lit as if you could choose them. If you hove over them they will subsequently lite correctly.

Expected Behavior: All valid lands should be lit

**Topic: Auriok Windwalker**

Issue: When playing the activated ability of Auriok Windwalker. Some target creatures are shaded as if they are not valid targets. In some cases, mousing over the shaded card removes shading.

Expected Behavior: Valid targets for Auriok Windwalker's ability should not be shaded

**Topic: Dawn's Reflection**

Issue: When playing Dawn's Reflection and you cancel before selecting the 2nd color it appears that the mana is in your mana pool even though it is not.

Expected Behavior: Mana should not appear in your mana pool if you cancel before selecting your 2nd color.

**Topic: Ferropede**

Issue: In some cases Ferropede will list a counter type that is not in play.

Expected Behavior: Ferropede should only list counter types that are in play

**Topic: *Fifth Dawn* symbol mismatch** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: *Fifth Dawn* symbol appear to be slightly different between the common and uncommon cards 

Expected Behavior: *Fifth Dawn* symbol should be identical on all cards 

### *Champions of Kamigawa*

**Topic: Targeting** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: The client does not allow spells which can target multiple permanents (i.e Decimate) to target the same permanent twice. 

Expected Behavior: Spells which can target multiple permanents should be able to target the same permanent multiple times. 

**Topic: Effects triggered by targeting**

Issue: A card with an effect triggered by becoming a target will trigger multiple times if the card is targeted more than once by the same spell. For example, if Decimate is copied with Mirari, the copy allows the same permanent to be targeted multiple times and the cards effect is triggered by each copy of the spell.

Expected Behavior: The effect should trigger once for the original spell and once for the copy.

**Topic: No brush symbol on CHK tokens**

Issue: None of the CHK tokens (spirit, Rat, Snake, Dragon, Illusion & Elemental) have the brush symbol when viewed in the card window

Expected Behavior: Brush symbols should appear to the left of the illustrator's name.

**Topic: No brush symbol on CHK flip cards**

Issue: None of the CHK flip cards have the brush symbol when viewed in the card window

Expected Behavior: Brush symbols should appear to the left of the illustrator's name.

**Topic: CHK Rat token has the "additional text" triangle**

Issue: The CHK rat token has an upside down triangle (indicating that there is additional rules text). When displayed in card view the triangle is yellow, when in play the triangle is grey.

Expected Behavior: There should be no "additional text" triangle on the CHK rat token.

**Topic: Flip Card Keyword Text**

Issue: Inverted keywords can not be clicked in order to get the keyword description.

Expected Behavior: Keyword description should be revealed when keyword is click regardless of text orientation

**Topic: Flip Card Text Disappears**

Issue: In collection view, the inverted text on flip cards disappears where the oracle text pop up appears

Expected Behavior: Inverted text should not disappear

**Topic: Brothers Yamazaki Collation Issue**

Issue: Brothers Yamazaki version a is available in boosters and Brothers Yamazaki version b is only available in tournament packs.

Expected Behavior: Versions a & b of Brothers Yamazaki should be available in both the Booster and Tournament pack.

**Topic: Brothers Yamazaki Collector Number**

Issue: Each version of The Brothers Yamazaki has a collector number of 160/306

Expected Behavior: One of The Brothers Yamazaki should be number 160a/306 and the other should be numbered 160b/306 respectively.

**Topic: Horobi, Death's Wail**FIXED 02.24.05 – Client Version v2.0.001.112

Issue: Horobi's triggered ability is destroying creatures that are not actually targeted by a spell or ability. (i.e. If Horobi and Arcbound Ravager are in play, Horobi will destroy Arcbound Ravager if Arcbound Ravager's activated ability is used) 

Note: This problem is wide spread and is occurring with other activated abilities that are not targeted abilities. 

**Topic: Shimatsu the Bloodcloaked** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: Shimatsu, the Bloodcloaked effect is allowing creatures to be sacrificed one at a time. 

Expected Behavior: All creatures should be sacrificed all at once 

**Topic: Sokenzan Bruiser** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: The creature type text for Sokenzan Bruiser appear in blue when the card is in play 

Expected Behavior: The creature type text should appear in black when the card is in play. 

**Topic: Otherworldly Journey**

Issue: Control of Otherworldly Journey's end of turn triggered ability is wrong. Controller of the target creature determines the order of the triggered ability.

Expected Behavior: Order of the End of Turn triggered abilities should be determined by the controller of Otherworldly Journey

**Topic: Cranial Extraction, Mindslaver** -- FIXED 02.24.05 – Client Version v2.0.001.112

Issue: In a 4 player game, when a Mindslaved player cast Cranial Extraction, the player targeted by Cranial Extraction hand is revealed to all players. 

Expected Behavior: The targeted player's hand should not be revealed to all players.
