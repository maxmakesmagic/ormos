# *Innistrad: Midnight Hunt* Set Mastery

*   24x *Innistrad: Midnight Hunt* boosters
*   5 Mastery Orbs (each can be redeemed for a card style on the *Innistrad: Midnight Hunt* Mastery Tree)

# *Innistrad: Midnight Hunt* Mastery Pass

![Innistrad: Midnight Hunt Set Mastery promo image](https://media.wizards.com/2021/images/daily/CY3WTYzIE6zb.png)

## Avatar

*   Wrenn

## Cards and Boosters

*   20x Boosters (4x MID, 4x AFR, 4x STX, 4x KHM, 4x ZNR)
*   10x *Innistrad: Midnight Hunt* mythic rare individual card rewards (ICRs)
*   Level 61+: 1x uncommon ICR

## CARD SLEEVES

*   Werewolf card sleeve
*   Transforming Arlinn exquisite card sleeve

## CARD STYLES

*   25 Mastery Orbs (each can be redeemed for a card style on the *Innistrad: Midnight Hunt* Mastery Tree)
*   15x Common card styles
*   10x Uncommon card styles

## EVENT TOKENS

*   1 Player Draft token (can be redeemed for either Premier Draft or Traditional Draft)

## GOLD AND GEMS

*   4,000 gold
*   1,200 gems

## PET

*   Drifter pet
*   Noble pet
*   Fisherman pet

# How many levels are there in *Innistrad: Midnight Hunt* Set Mastery?

The *Innistrad: Midnight Hunt* Set Mastery goes up to level 60. All players receive rewards through level 48, while players with the Mastery Pass will receive rewards up to level 60, and beyond!
