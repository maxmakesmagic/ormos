「かっちん(＝森)の協調に、ホント助けられましたね」

とは、インタビューしたときの津村の第一声。その言葉の通り、津村のデッキは大量の白の優良カードに恵まれた、素晴らしい仕上がりのデッキになった。

だが実際のところ、森の初手が《特務魔道士ヤヤ・バラード/Jaya Ballard, Task Mage》、これは文句ないとしても、津村に《裂け目の稲妻/Rift Bolt》が流れ、実際にこれを津村がピックしていたため、悪くすれば共倒れの危険すら感じられたのは確かだ。

そして結果的には2人とも赤を使うことになったのだが、互いのデッキの方向性を考えることで正面衝突を防いだ。具体的には、津村はカードパワーよりもデッキのまとまりを優先し、その結果として森には《無慈悲なる者ケアヴェク/Kaervek the Merciless》をはじめとした、一撃必殺のカードが多く流れ込むこととなったのである。

森の協調姿勢が感じられたポイントとして、津村は第3パック8手目の《ヴェク追われの盲信者/Zealot il-Vec》を挙げた。回避能力兼クリーチャー除去のようなこのクリーチャーは、地味ながら白の必須カードとされている。このカードが回ってきたことが、ドラフトの成功を示していると感じられたのだろう。

よく言われることではあるが、こうした「協調」はカードの強さの理解と互いの信頼が欠かせない。その点で、津村と森は世界でも最高クラスのコンビであり、その結晶がこのデッキと言える。

やや乱暴にまとめると、  
 「デッキ強い系」の津村に対し、  
 「カード強い系」の森という対比になっているといえよう。

それでは、実際の対戦の中から、第9回戦の津村vs.石田戦の模様をお送りしよう。この時点で、津村は残念ながら第7回戦で敗北を喫し、3敗と苦しい立場に立たされている。互いにもう負けられない勝負だ。石田は白青のデッキを用いており、同系統デッキの対戦でもある。

### Game 1

先に主導権を握ったのは石田。《遍歴の宿命語り/Errant Doomsayers》こそ津村の《鋸刃の矢/Serrated Arrows》で失うものの、《騎兵戦の達人/Cavalry Master》に《グリフィンの導き/Griffin Guide》をつけ、津村の《ケルドの矛槍兵/Keldon Halberdier》が待機から目覚めればそこにバウンス（《応じ返し/Snapback》）とリードを広げる。

しかし、津村も《グリフィンの導き/Griffin Guide》を《雲を追うケストレル/Cloudchaser Kestrel》で叩き割り、逆に自らの《グリフィンの導き》をこの《雲を追うケストレル》にプレイして戦線を立て直す。

さらに《アムローの偵察兵/Amrou Scout》、そこから《ヴェク追われの盲信者/Zealot il-Vec》を連打する。1体だと限界があるし心もとないが、2体いると俄然心強いカードだ。  
 さらに、それと並行して《セラの報復者/Serra Avenger》をも追加し、相手の陣形を切り崩す。

最後には、《ボガーダンの憤怒獣/Bogardan Rager》でもって、粘る石田に止めを刺した。

**津村 -1 石田 -0**

### Game 2

ここで、石田がダブルマリガンの憂き目にあってしまう。

これは津村の圧勝か、と思われたが、石田の展開は《トゲ尾の仔ドレイク/Spiketail Drakeling》《ちらつくスピリット/Flickering Spirit》とマリガンを感じさせないもの。一方の津村も、土地は《平地/Plains》のみながら《アムローの偵察兵/Amrou Scout》の2連打というスタートで応える。

しかし、石田の少ない手札はあまりにも効率的だった。《ちらつくスピリット》に《グリフィンの導き/Griffin Guide》を装着してクロックを早めると、《アムローの偵察兵》から呼び出されてきた《遍歴の宿命語り/Errant Doomsayers》を《応じ返し/Snapback》で即バウンスして足を止めない。

自らの《遍歴の宿命語り》は続いて呼び出された《ヴェク追われの盲信者/Zealot il-Vec》で失うが、津村が《セラの報復者/Serra Avenger》《遍歴の宿命語り》と並べてターンを返してきたところで、手札ゼロの石田は、

トップデッキ《時間の渦/Temporal Eddy》！

これには津村も降参するしかなかった。マジックは何が起こるか分からないもの。最善の手を続けていけば、こういう幸運もあるのだ。

**津村 -1 石田 -1**

### Game 3

勝利目前から一転、瀬戸際に追いこまれた津村。逆に、俄然意気上がるであろう石田。大事な第3ゲームに意気込みもあるはずだが、両者の見た目は至って平静である。

ゲームは後手石田の《ヴィセリッドの深み歩き/Viscerid Deepwalker》待機から幕が開く。津村のファーストアクションは《アヴナントの癒し手/D'Avenant Healer》となった。

ここに石田の《コーの先導/Outrider en-Kor》が追加され、津村は《鋸刃の矢/Serrated Arrows》で迎え撃つ構え。石田は《アムローの求道者/Amrou Seekers》をプレイしてから攻撃し、津村は《鋸刃の矢》で《コーの先導》を1/1に縮めてクロックを軽減した。

津村のプレイ《ヴェク追われの盲信者/Zealot il-Vec》に対し、ここで《ヴィセリッドの深み歩き》が待機終了。これを含めた石田の総攻撃に対し、《アムローの求道者》は《アヴナントの癒し手》で止めつつ（自分へのダメージを軽減）、2発目の矢が《コーの先導》を葬る。

石田は《時間の渦/Temporal Eddy》を《ヴェク追われの盲信者》へ打ち、津村はこれを再召喚して時間が過ぎた。

この隙にと、石田は《グリフィンの導き/Griffin Guide》を《ヴィセリッドの深み歩き/Viscerid Deepwalker》につけ、力強く攻撃して全力パンプアップ。クロックを軽減したい津村は、最後の《鋸刃の矢》と《アヴナントの癒し手》でダメージを5点にまで減らす。

そして、ここでまたしてもの《雲を追うケストレル》が《グリフィンの導き》を叩き割る。さらに《セラの報復者/Serra Avenger》が場に送られ、制空権は徐々に得られたか。

だが、《ヴィセリッドの深み歩き》は1/2とはなったものの、まだ盤上へのインパクトは大きい。これが攻撃し、津村が《雲を追うケストレル》でブロックすると、石田は十分量のパンプアップののち《一瞬の瞬き/Momentary Blink》。《雲を追うケストレル》を葬りつつ、《ヴィセリッドの深み歩き/Viscerid Deepwalker》をフレッシュな状態に戻してみせた。

しかし、津村のサイドインした《ジェディットの竜騎兵/Jedit's Dragoons》が間に合い、その間に《セラの報復者》《ヴェク追われの盲信者》が走る。この《ジェディットの竜騎兵》は《ヴィセリッドの深み歩き》と相打ちになるが、ここまで仕事ができれば上々の戦果である。

そのまま津村が、《ヴェク追われの盲信者》に《グリフィンの導き》をエンチャントして押し切ったのだった。

**津村 -2 石田 -1**
